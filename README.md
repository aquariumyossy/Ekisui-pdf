# ekisui-pdf

日本語の法律文書 PDF を、そのパソコンの中だけで墨消しする Windows アプリです。易水会の勉強会で配ることを想定しています。通信はしません。OCR も墨消しも、開いた PDF も、外には出ません。

ライセンスは **AGPL-3.0** です。PDF の処理に PyMuPDF を使っているため、アプリ全体をこのライセンスで配布します。`LICENSE` と `THIRD_PARTY_NOTICES.md` を同梱しています。

墨消しは人が確認するものです。保存のあと画面に「消した語句は見つかりませんでした」と出ても、それだけで安全ではありません。出力した PDF を自分の目で読み、必要な箇所が消えているか確かめてください。迷ったら、そのファイルを提出しないでください。

## 動作環境

- Windows 10 または Windows 11（64 ビット）
- インストール先はユーザーのフォルダです。管理者権限は要りません
- 実行中にインターネットは使いません。OCR のモデルはインストーラに入っています

縦書き、手書き、JPEG や TIFF の単体画像は、この版の対象外です。対象は、横書きのスキャン PDF と、すでに文字が入っている PDF です。

### SHA-256 を確認する

PowerShell で、インストーラを保存したフォルダに移動して次を実行します。

```powershell

```

表示されたハッシュが、配布元の一覧と一致することを確認してください。GitHub Actions の `installer` ジョブのログにも、同じ `Get-FileHash` の結果が出ます。アーティファクト名は `ekisui-pdf-0.1.0-win64-setup` です。

## 使い方

1. **開く** で PDF を開く。ページの縮小版と、拡大縮小できる本文が出ます
2. 文字が入っていないページだけ **OCR実行** する。すでに文字があるページはその文字を使います。OCR の ▾ で **自動傾き補正** を切れます（初期値はオン）。向きや傾きを直したページは、その画像のまま保存されます。直した量はサムネイルに出ます
3. 読みが怪しい行は **OCR修正** タブで、行をクリックして直す。Enter で確定、Esc で取消です
4. **自動候補** は電話番号、メール、口座番号、郵便番号、住所、英数字、人名を候補にするだけです。確定はしません
5. **語句で探す** と **範囲で選ぶ** で、候補を足せます。空白や改行、全角と半角、読み間違いやすい字は揃えてから探します
6. 各候補は **黒塗り** か **置換** です。人名と会社は置換、電話・メール・住所・口座・郵便は黒塗りが初期値です。呼び名は会社A、個人甲のように自動で付き、同じ語句は全ページで同じ呼び名になります
7. **置換表** で表記ゆれをまとめられます。置換表は PDF には入りません。保存するときは別ファイルです
8. **確定** で、選んだ範囲の画像の画素と文字を消す処理を確定します。黒い四角を上に描くだけではありません。置換は、消したあとに呼び名を書き込みます。**枠の幅をそろえる**（初期値オン）は、短い語句の枠をおよそ5文字分まで広げます。長い語句は短くしません
9. **保存** は必ず別名です。元のファイルは上書きしません。初期値では、メタデータを消し、墨消し記録の CSV を出します。記録に元の語句を入れるスイッチはオフです
10. 保存の直後に、保存したファイルを開き直し、消したはずの語句が残っていないかを同じルールで探します。残っていれば一覧と移動ボタンが出ます

画面の説明は、ボタンにマウスを乗せたときに出ます。

## OCR

PaddlePaddle を Windows に同梱するのは、CPU 用の依存関係と PyInstaller での配布が不安定なため見送りました。認識に使う重みは PP-OCRv5 の mobile モデル（検出・認識・行の上下判定）で、実行は ONNX Runtime の CPU だけです。認識モデル `ch_PP-OCRv5_rec_mobile` は中国語・英語に加えて日本語を学習したモデルです。日本語専用の PP-OCRv5 認識モデルは配布されていません。

モデルの入手元とハッシュは `models/SHA256SUMS` と `THIRD_PARTY_NOTICES.md` にあります。起動時にモデルを取りに行く処理はありません。

## 開発

```powershell
python -m pip install -e ".[dev]"
python tools/verify_models.py
python -m pytest
```

テストは、日本語を画像にしたスキャン風 PDF（傾いたページを含む）で、文字レイヤ、傾き補正、画素の削除、呼び名、メタデータ、表記ゆれ、消し残しの検出を確認します。通信しないことも、ソケットを塞いだ状態で OCR を読み込んで確認します。

画面は PySide6 です。オフスクリーンのスクリーンショットは `docs/screenshots/` にあります。

## 既知の制限

- 検証は保存後の文字レイヤとメタデータを見ます。画像の中の文字をもう一度 OCR して探す処理ではありません
- ページ面積の約6割以上を、4千画素以上の画像が占めるとき（ページの回転を反映し、分割された画像は合わせて数えます）、見えている文字が無ければスキャンとして読み直します。複合機の見えない文字層は数えません。傾きを直し、保存するページは直した画像から作るので、古い文字は写しません。OCR の前に保存しようとすると、読み取ってから保存するよう止めます。見えている文字が1字でもあるページは、短い表紙でも、大きな図があっても、その文字を使います。画像の無い空白ページはそのまま保存できます。スキャン上に見えているページ番号やファクスヘッダがあると、そのページは読み直しません
- 文字の位置は、テキストPDFでは文字ごとの箱、スキャンでは文字幅（全角と半角）で置きます。検証は語句全体に加えて、8文字以上の語句の前半と後半が残っていないかも見ます。画像をもう一度 OCR する検証ではありません
- 半角カタカナの濁点（ﾀﾞ など）と、段組で横に並んだ行は、取りこぼすことがあります
- 検出器はページの長辺を960ピクセルに縮小してから文字の位置を探します。ごく小さい文字は拾えないことがあります
- 人名の下の名前がひらがなだけの場合（山田たろう）は自動候補にしません。語句検索は使えます
- 自動候補は行の中だけを見ます。行をまたいだ電話番号は拾いません。語句検索は、近い行の折り返しはつなぎます
- 英数字の自動候補は、英字を1字以上含む3文字以上です。数字だけの列は口座や電話の規則に任せます。初期状態ではチェックが外れています
- 読み間違いやすい字（フとプなど）の候補は、自動候補でも最初から選択されます。それ以外のゆるい一致は、語句検索で出します
- 枠の幅をそろえても、長い名前の枠は短くなりません。長さから名前を推測される余地は残ります
